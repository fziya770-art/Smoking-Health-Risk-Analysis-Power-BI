🚬 Smoking Health Risk Analysis | Power BI
📊 Project Overview
The Smoking Health Risk Analysis Dashboard is an interactive Power BI project developed to analyze the relationship between smoking habits, patient demographics, organ conditions, and associated health risks.
The dashboard transforms healthcare-related data into meaningful visual insights, helping users explore patterns in smoking behavior and its potential impact on different health conditions.
🎯 Objectives
Analyze smoking patterns among patients
Understand the distribution of smokers across different age groups
Analyze gender-wise smoking patterns
Examine the impact of smoking on different organs
Compare healthy and affected patients
Identify patterns in smoking-related health risks
Create an interactive and user-friendly Power BI dashboard
🛠️ Tools & Technologies
Power BI – Dashboard development and visualization
Power Query – Data cleaning and transformation
DAX – Calculated measures and KPIs
Excel / CSV – Data source
Data Visualization – Interactive charts and reports
📌 Key Analysis Areas
The dashboard provides analysis of:
Total Patients
Smoking Status
Age Groups
Gender Distribution
Organ Conditions
Healthy vs Affected Patients
Smoking-related Health Risks
Patient-level health information
📈 Dashboard Features
👥 Patient Overview
Provides an overall view of the number of patients included in the dataset.
🚬 Smoking Analysis
Analyzes smoking status and identifies patterns among smokers and non-smokers.
🫀 Organ Health Analysis
Examines different organ conditions and identifies the number of patients affected by each condition.
👨‍⚕️ Healthy vs Affected Patients
Provides a comparison between patients classified as healthy and those with affected organs or health conditions.
📊 Demographic Analysis
Explores patient characteristics such as age and gender to identify patterns within the dataset.
🎛️ Interactive Filters
Users can interact with the dashboard using available slicers and filters to explore specific patient groups and health conditions.
🔄 Data Preparation
The dataset was cleaned and transformed before developing the dashboard.
The data preparation process included:
Handling missing values
Removing unnecessary columns
Removing duplicate records where required
Correcting data types
Cleaning inconsistent values
Transforming data using Power Query
Creating calculated measures using DAX
